# Hype Optimize — Beta 0.00

Instalador próprio para Windows 10/11 x64.

[Baixar setup do canal beta](https://github.com/WandzR/hype-optimize-updates/releases/download/beta/Hype-Optimize-Setup.exe)

Esta beta libera o motor para validação local. Conta, cobrança e licença comercial serão configuradas separadamente. O aplicativo inicia em Visão geral e usa a identidade do Hype.

O canal beta verifica o manifesto Ed25519 e o hash completo do instalador antes de instalar uma atualização. O manifesto de cada versão acompanha os arquivos da release. A assinatura do manifesto pertence ao Hype; certificado Authenticode do Windows ainda não está configurado.

Este repositório distribui instaladores. O código do aplicativo permanece privado. A homologação instalada completa do Hype continua em validação.
